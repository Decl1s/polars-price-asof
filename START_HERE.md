Я начинаю с README demo и команды inspect. Затем иду по карте:

Я ставлю точку остановки после join_asof: O002 должен иметь A2, O006 — NULL,
O005 — C1. Затем смотрю age_seconds:0, NULL,7201. Только после этого смотрю status
и amount_minor. Я не отлаживаю сумму, пока не объясню выбор версии каждой строки.
Без отладчика я вижу те же поля в inspect и decisions.parquet.

Я сортирую обе таблицы сам и сохраняю два временных ключа через coalesce=False.
Я отделяю выбор последней исторической цены от политики её возраста, чтобы не
потерять причину stale. Я не выбираю first/last при неоднозначном price key.
За этими короткими решениями стоят бизнес-правила; подробно я разобрал их в NOTES.

В `.vscode/tasks.json` я подготовил четыре задачи. Я выбираю Python своего venv
и новое имя результата для следующего запуска. Установку расширений и GUI IDE
проверкой команд не подменяю. Упражнения выполняю на копиях входов, исходное demo
не использую как папку для собственных документов.
